# Movoa Userscript

Unlimited AI video generator with sound: on paid plans the tenth take of a shot costs what the first did, and your first clip is free to make right now. Turn selected text on any web page into an AI video clip with synchronized audio via [Movoa](https://movoa.ai/?utm_source=greasyfork&utm_medium=userscript) — supporting [text to video](https://movoa.ai/video/text-to-video), [photo to video](https://movoa.ai/video/photo-to-video), and [AI video with audio](https://movoa.ai/video/ai-video-with-audio).

## Install

1. Install a userscript manager (Tampermonkey, Violentmonkey, or ScriptCat).
2. Install [`movoa.user.js`](./movoa.user.js) from Greasy Fork, OpenUserJS, or ScriptCat.
3. Sign in on [movoa.ai](https://movoa.ai/?utm_source=greasyfork&utm_medium=userscript) and create an API key at [movoa.ai/settings/apikeys](https://movoa.ai/settings/apikeys).
4. Highlight any text on a page and click **🎬 Video** (or open the extension menu and choose **Set Movoa API key…**).

Runs cost credits on your Movoa account, at the prices on [movoa.ai/pricing](https://movoa.ai/pricing).
